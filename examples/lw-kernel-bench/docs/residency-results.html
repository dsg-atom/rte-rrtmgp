Read this: the aqua and orange curves are the same GPU kernel. The ~30× vertical gap between them is pure data movement — kept on-device it disappears, paid per call it swallows the speedup. Individual-kernel offload (orange) barely beats one core and loses at small sizes; the compute engine (aqua) is 40–61× faster only when the arrays stay resident across the radiation call chain.
